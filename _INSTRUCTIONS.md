# Sapar — доработка маршрутов

## Что было не так
- Маршрут терялся после перезагрузки страницы; переключатель «Доступно офлайн» ничего не делал.
- Расстояние в сводке — грубая эвристика «40 км × остановки».
- В окне AI можно выбрать 2/3/7 дней, но backend всегда строил маршрут на один день.
- Окно AI было только на русском.
- Маршрут нельзя было посмотреть на карте.
- «Рядом с вами» показывало жёстко прописанные расстояния; `/api/locations/nearby` игнорировал
  координаты, а `sortByDistance` ждал `{lat, lon}` вместо `[lat, lon]`.
- Модель `Itinerary` хранила `userId` и `locId` как ObjectId — сохранение маршрута с Clerk userId
  (`user_...`) и числовыми id мест падало бы с ошибкой; `GET /api/itinerary/:id` не существовал.
- Без `CLERK_SECRET_KEY` любой запрос к `/api/itinerary` падал с 500 (теперь — понятный 503).
- Backend на Node 20 не мог импортировать `frontend/src/data/locations.js`
  (в `frontend/package.json` не было `"type": "module"`).

## Что теперь работает
1. **Сохранение маршрута** в localStorage (`sapar_itinerary`), кнопки «Демо-маршрут» и «Очистить».
2. **Расстояние по координатам**: сумма отрезков по формуле гаверсинуса × 1.3 (поправка на дороги).
   Координаты берутся из пункта, из каталога по `locId` или по совпадению названия.
   Если координат не хватает — прежняя оценка с пометкой «~».
3. **Бюджет**: еда ~4000 ₸, ночёвка ~15000 ₸, место ~2500 ₸ + бензин 30 ₸/км.
4. **Многодневные маршруты**: поле `day` у пунктов, разделители «День N», бейдж «3 дня»
   с правильным склонением. Стрелки ↑/↓ меняют пункты местами внутри дня (время остаётся
   по порядку), а на границе дня переносят пункт в соседний день. Место, добавленное кнопкой
   «Добавить в маршрут», получает время после последнего пункта (позже 21:00 — следующий день).
5. **Groq** получает каталог мест с координатами, число дней и язык интерфейса; ответ
   нормализуется (время, дни, иконки, координаты только в пределах Казахстана).
6. **Демо-генератор** (нет ключа или ошибка Groq) строит маршрут из каталога по интересам.
7. **Карта**: переключатель «Все места / Маршрут», нумерованные остановки, пунктирная линия,
   автоподгонка масштаба.
8. **«Рядом с вами»** — расстояние от реальной геопозиции, если она разрешена.
9. **Тесты**: `npm test` (node:test, без новых зависимостей).

## Ключевые файлы
- `frontend/src/lib/geo.js`, `frontend/src/lib/route.js` — расчёты расстояния, времени, бюджета, дней
- `frontend/src/hooks/useItinerary.js`, `frontend/src/hooks/useGeolocation.js`
- `frontend/src/screens/ItineraryScreen.jsx`, `MapScreen.jsx`, `DiscoveryScreen.jsx`
- `frontend/src/components/ui/AIRouteModal.jsx`, `frontend/src/i18n/LanguageContext.jsx`
- `backend/src/services/aiRoute.service.js`, `backend/src/services/geo.service.js`
- `backend/src/models/Itinerary.model.js`, `backend/src/controllers/*`

## Как проверить
1. `npm install && npm run dev`, открыть http://localhost:3000
2. «Маршрут» → в сводке реальное расстояние (~380 км для демо-маршрута) → «Показать на карте».
3. AI-баннер → «3 дня» → «Сгенерировать» → три дня в маршруте → обновить страницу (маршрут на месте).
4. Профиль → ENG → окно AI на английском.

`npm install` нужен только если ещё не ставили зависимости — новых пакетов нет.
