# Sapar — Визуальный редизайн (этно-модерн + минимализм)

## Что в архиве
15 изменённых файлов. Всё остальное в проекте трогать не нужно.

## Как применить (просто)
1. Распакуй архив `sapar-redesign.zip`
2. Внутри увидишь папку `frontend/` — она повторяет структуру твоего проекта
3. Перенеси/замени файлы поверх своих в `sapar-main/` (с подтверждением замены)
4. Запусти локально: `cd frontend && npm run dev`
5. Если ОК — закоммить: `git add . && git commit -m "feat: visual redesign — этно-модерн + минимализм" && git push`
6. Vercel сам пересоберёт прод

## Что именно поменялось
- **Палитра** (`theme.js`): добавлена терракота `#C97B5A`, мягкий фон `#FAFAF7`, нейтрали ink
- **Tailwind config**: новые цвета, теневые пресеты `card/soft/lift`, шрифт `font-display` (Playfair)
- **global.css**: подключён Playfair Display для заголовков-акцентов, мягче press-эффект
- **Скругления**: всё округлено — `rounded-2xl` (карточки), `rounded-xl` (кнопки), `rounded-full` (чипы, тогглы)
- **Орнамент**: переделан под казахский «қошқар мүйіз» (бараний рог)
- **Header у всех экранов**: скруглённый низ (`rounded-b-3xl`), контент «выезжает» из-под него с `marginTop: -16/-20`
- **Карточки**: мягкие тени `0 4px 20px rgba(31,41,55,0.06)` вместо плоских
- **BottomNavbar**: активный таб теперь как pill (овальная подложка)
- **Иконки в шапках**: убраны в квадраты со скруглением + блюр
- **Premium-карточка**: добавлен лёгкий орнамент-фон + чек-иконки в кружках
