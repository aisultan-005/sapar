# Sapar — Динамический заголовок и сводка маршрута

## Что было сломано
- Заголовок «Алматинская область» всегда один и тот же, даже после AI-генерации
- Плашка «1 день» всегда «1»
- Сводка «280 км / ~4.5ч / ~25к ₸» — жёстко прописана, не зависит от маршрута

## Что теперь работает
1. **Заголовок** меняется на тот, что вернул Groq (например «Природа Чарына: однодневный маршрут»)
2. **Плашка дней** считается автоматически: 1 день если ≤5 пунктов, 2 дня если ≤10, и т.д.
3. **Расстояние** ≈ 40 км × (количество остановок - 1) — грубая эвристика
4. **Время** = сумма длительностей всех пунктов (парсит «1ч», «1.5ч», «30мин», «—»)
5. **Бюджет** ≈ 5000 ₸ × количество остановок

Все цифры теперь меняются от маршрута к маршруту.

## Изменённые файлы (3 штуки)
- `frontend/src/hooks/useItinerary.js` — теперь хранит `title`, `replaceItems` принимает объект `{title, items}` целиком
- `frontend/src/screens/ItineraryScreen.jsx` — принимает `title` пропсом, вычисляет сводку из items
- `frontend/src/components/layout/SaparMainShell.jsx` — передаёт `title` в ItineraryScreen, корректно передаёт `data` в replaceItems

## Как применить
1. Распакуй архив, перенеси файлы поверх своих (с заменой)
2. **`npm install` НЕ нужен**
3. Закоммить:
   ```bash
   git add .
   git commit -m "feat: dynamic itinerary title and summary"
   git push
   ```

## Как тестировать
1. После деплоя зайди на сайт, обнови (Ctrl+Shift+R)
2. Нажми AI-баннер → выбери теги/длительность/бюджет → «Сгенерировать»
3. После генерации на вкладке «Маршрут» должны быть:
   - Новый **заголовок** от Groq (вместо «Алматинская область»)
   - Цифры сводки, **соответствующие** новому количеству остановок
4. Сгенерируй ещё раз с другими настройками — должно стать другое

## Что точно НЕ меняется автоматически
Эвристика расстояния/бюджета — приблизительная (40 км × остановки, 5к × остановки). Если хочешь точное расстояние — нужно считать через координаты мест (Haversine между точками), но для этого Groq должен возвращать координаты, а он сейчас даёт только название. Это уже отдельная задача — скажешь в следующем чате если важно.
